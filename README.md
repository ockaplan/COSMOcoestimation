This code is mainly provided for review, hence why it is not straightforward to run locally.

To run this code locally, you must create the following directories within the cloned repo: /models/, /figures/, /data/, /logs/.
Then, download Swarm data and place in /data/. Update the code to pull data from the correct .cdf(s). Update Dst data as required.
